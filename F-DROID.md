# F-Droid Submission (GitHub Source)

TickTock stays hosted on GitHub.

F-Droid uses a separate metadata repository, so the app source remains:
- https://github.com/leodp/TickTock

## Files Prepared In This Repository

- metadata/com.ticktock.app.yml

## What Is Already Ready

- Stable application id: com.ticktock.app
- GitHub source URL and issue tracker in metadata
- Release tag pinned in metadata: v1.0.0

## Final Submission Steps

1. Fork https://gitlab.com/fdroid/fdroiddata
2. Copy metadata/com.ticktock.app.yml into metadata/com.ticktock.app.yml in your fork
3. Commit on a branch (example: ticktock-v1.0.0)
4. Open a merge request to fdroid/fdroiddata master

After the merge request is accepted and the pipeline passes, F-Droid can build and publish TickTock from GitHub.
